Features

One app for the whole job.

millvane follows the part from the first sketch to the program on the control. Every step works on the same model, the same setup and the same machine — nothing is typed in twice.

Design

Constrained sketches, extrude, fillet, chamfer, shell and patterns. Parameters drive the model, holes carry thread and fit, STEP files go in and out.

Manufacture

Place part and stock in the fixture, build the tool list and the operations, generate the paths and post the program — with your cutting data per operation.

vaneflow adaptive roughing

Roughing built around a steady tool load and staying in the cut: links run through cleared material instead of climbing to a safe height and back.

Machine simulation

Your machine as a kinematic model: axes, travel limits, trunnion table, spindle, holders and fixtures. The stock is cut as the program runs.

Collision checking

Tool, holder and spindle against stock, part, fixture and table — in rapids and in feed. Every finding is listed with the program line that caused it.

Prove A/B

Load the original program as A and the revision as B. See the code differences, run both and compare the finished parts for material left or taken.

Setup sheets

A printable sheet for the operator: stock, workholding, work offsets, tools with stick-out, operations in order and the cycle time.

Tool library

Tools, holders and cutting data in one library that grows with your shop. Holders come from STEP, so the collision model matches the real one.

3+2 indexed 5-axis

Machine several faces in one clamping. Each orientation gets its own work offset, and every table tilt is simulated and checked like any other move.

Workflow

Design → Manufacture → Simulate.

Three workspaces, one project. Change the model and the operations follow; change an operation and the simulation shows what it does.

  1. 01

    Design

    Model the part or open a STEP file. Holes carry their thread and fit, faces keep their colours.

  2. 02

    Manufacture

    Pick machine, fixture and stock. Add operations, choose tools, generate the paths and post the G-code.

  3. 03

    Simulate

    Run the program on the whole machine, line by line, with the stock being cut and every collision listed.

Roughing that stays in the cut.

vaneflow clears pockets and open areas with trochoidal, adaptive moves, so the tool sees a steady load instead of full-width slotting in the corners. To reach the next region it travels through material that is already gone — no climb to the clearance plane and back down.

  • Steady engagement, so the full flute length can work
  • Links stay down in cleared areas: fewer retracts, less air time
  • Stepover, stepdown, allowances, feeds and cut direction are yours to set, per operation
  • Safe first: every path is checked against stock, part and fixture

Machine sandbox

Crash it here, not on the machine.

millvane reads G-code the way the control does — work offsets, tool lengths, canned cycles, table moves — and drives a model of the whole machine. Tool, holder, spindle and fixture are checked against the stock as it is being cut.

Questions

Which machines does millvane support?

3-axis mills and 5-axis machines with a trunnion table (a tilt axis plus a rotary axis), programmed in ISO G-code. More machine types and controls are planned — tell us what you run.

Does it do simultaneous 5-axis?

Not today. millvane programs 3-axis and 3+2 indexed work. The simulation runs the table axes like every other axis, so programs that move them are simulated and checked.

Does it need an internet connection?

No. millvane is a Windows desktop app. Your models, programs, setups and library stay on your computer — see the privacy policy.

When is it available?

Testers get access first. The public release and the prices will be announced on this site.
